Spring JPA

  • JPA (Java Persistence API)
  • 자바로 영속 영역을 처리하는 API
  • Spring Data JPA 라이브러리 사용
  • ORM(Object Relational Mapping)
    • 객체지향으로 구성한 오브젝트를 관계형 DB에 매핑하는 개념
  • JPA Repository
    • 객체지향을 통해서 영속 계층 처리
    • 엔티티 객체 -> 데이터(VO/DTO) -> JPA -> 데이터베이스 연동
    • Spring Data JPA
      • 엔티티 객체를 이용 -> JPA를 사용하기 위한 라이브러리 제공
      • 자동으로 객체 생성, 처리 -> JpaRepository
    • 엔티티 객체(클래스) <- VO, DTO와 비슷함
      • 해당 클래스명으로 테이블이 생성
      • PK 기본키를 가지는 자바 객체
      • @id 객체 구분 처리
      • 수정 안하는 것이 권장
      • 해당 클래스명으로 된 테이블이 존재하지 않으면 생성
      • @Entity 필수
      • 키 생성 전략(Key generation strategy)
        • GenerationType.IDENTITY -> 데이터베이스에서 자동 생성
        • GenerationType.IDENTITY -> 데이터베이스에 위임하여 생성
          • MariaDB, MySQL, MSSQL -> auto_increment
          • Oracle -> sequence -> @SequenceGenerator
        • TABLE : 키 생성용 테이블 사용, 모든 DB에서 사용 -> @TableGenerator 필요
        • AUTO : DBMS에 따라서 자동 지정, 기본값
    • JpaRepository 인터페이스 사용
    • Spring Data JPA 사용
      • JpaRepository 인터페이스 선언
      • -> 대략적인 DB 관련 처리 가능
      • -> MyBatis 매퍼 인터페이스와 유사한 기능
    • 엔티티 타입, @id 타입 지정 필수
    • 확장에 대한 이슈
      • 쿼리 메서드 기능(메서드명 자체가 쿼리가 되는 기능)
      • Querydsl 이용(거의 안씀)
    • 클래스명(엔티티명)
    • insert/update
      • save(객체명)
    • select
      • findBy(ID)
    • delete
      • deleteBy(ID)
  • 페이지 처리
    • Pageable 사용
    • 인터페이스
    • Pageable 객체를 파라미터로 사용
      • PageRequest.of(페이지 번호, 사이즈)
      • PageRequest.of(페이지 번호, 사이즈, sort)
      • PageRequest.of(페이지 번호, 사이즈, sort, direction 속성)
  • JPQL(Java Persistence Query Language)
  • @Query 로 value로 쿼리 작성
  • JPA에서 사용하는 쿼리 언어
    • 데이터베이스와 독립적으로 사용 가능
    • JPQL 이용
  • 테이블 대신 엔티티 타입을 이용, 컬럼 대신 엔티티 속성을 이용
  • SQL을 대신하는 용도
  • 조인과 같이 복잡한 쿼리 실행 가능
    • @Query("SELECT B FROM tbl_bbs AS B WHERE B.title LIKE concat("%", aaa, "%")")
      Page<Board> findKeywords(String k, Pageable p)
  • nativeQuery = true 특정 데이터베이스에서 동작하는 쿼리 사용 가능
    • fetch() -> 쿼리 실행
    • 단점
      • 어노테이션을 사용하므로 제약이 존재, 쿼리가 고정된 형태
      • 컬럼을 동적으로 검색하기 어렵다
  • Querydsl 이용
