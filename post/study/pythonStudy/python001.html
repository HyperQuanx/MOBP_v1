파이썬 기본 자료형 및 연산자
번호 내용 설명
1 파이썬의 기본 자료형
  • Text: str
  • Numeric: int, float, complex
  • Sequence: list, tuple, range
  • Mapping: dict
  • Set: set
  • Boolean: bool
  • Binary: bytes, bytearray, memoryview
2 연산자의 종류
  • 사칙연산
  • 제곱 연산자 **
  • 나머지 연산자 %
  • 버림 연산자 //
3 문자열 자료형
  • 큰 따옴표 (")
  • 작은 따옴표 (')
  • 큰 따옴표 연속 3개 (""")
  • 작은 따옴표 연속 3개 (''')
  • 따옴표 안에서 따옴표 표시 가능
