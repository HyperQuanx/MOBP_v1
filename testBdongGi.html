Fetch, Ajax, Axios Comparison

1. 기본 정의

  • Fetch API: JavaScript에 내장된 현대적인 HTTP 요청 API. 브라우저에서 기본 제공되며 Promise 기반으로 작동. 간결하고 표준화된 방식으로 HTTP 요청을 처리.
  • Ajax (Asynchronous JavaScript and XML): 기술 개념으로, 페이지를 새로고침하지 않고 서버와 비동기적으로 데이터를 주고받는 방식을 의미. XMLHttpRequest 객체를 사용해 구현. 라이브러리로는 jQuery.ajax()가 일반적으로 사용됨.
  • Axios: JavaScript HTTP 클라이언트 라이브러리. Node.js와 브라우저에서 모두 작동하며 Promise 기반. Fetch보다 더 많은 기능을 제공하며, 직관적인 문법과 풍부한 확장성을 갖춤.

2. 사용법 비교

a. Fetch

fetch('https://api.example.com/data')
  .then(response => {
    if (!response.ok) throw new Error('Network response was not ok');
    return response.json();
  })
  .then(data => console.log(data))
  .catch(error => console.error('Fetch error:', error));

b. Ajax (jQuery)

$.ajax({
  url: 'https://api.example.com/data',
  method: 'GET',
  success: function(data) {
    console.log(data);
  },
  error: function(error) {
    console.error('Ajax error:', error);
  }
});

c. Axios

axios.get('https://api.example.com/data')
  .then(response => console.log(response.data))
  .catch(error => console.error('Axios error:', error));

3. 주요 차이점

a. 브라우저 내장 여부

  • Fetch: 브라우저에서 기본 제공 (추가 라이브러리 설치 불필요).
  • Ajax: 브라우저가 아닌 jQuery 라이브러리가 필요.
  • Axios: 추가로 설치해야 하는 라이브러리 (npm install axios).

b. Promise 지원

  • Fetch: 네이티브 Promise 기반.
  • Ajax: 콜백 기반 (Promise를 사용하려면 별도의 래퍼 필요).
  • Axios: Promise 기반.

c. JSON 데이터 처리

  • Fetch: 응답 데이터를 JSON으로 변환하려면 .json() 메서드 사용 필요.
  • Ajax: JSON 데이터 처리가 자동으로 이루어짐.
  • Axios: 응답 데이터가 자동으로 JSON으로 변환.

d. 에러 처리

  • Fetch: HTTP 상태 코드(예: 404, 500)가 에러로 간주되지 않음. 반드시 .ok 속성을 확인해야 함.
  • Ajax: HTTP 상태 코드를 자동으로 에러로 처리.
  • Axios: HTTP 상태 코드를 자동으로 에러로 처리.

e. 기능 지원

기능 Fetch Ajax Axios
기본 제공 여부 브라우저 내장 jQuery 필요 외부 라이브러리 필요
Promise 지원 ✅ ❌ (콜백 기반) ✅
JSON 자동 변환 ❌ (수동 필요) ✅ ✅
인터셉터 지원 ❌ ❌ ✅

f. 요청 취소

Fetch:

const controller = new AbortController();
fetch('https://api.example.com/data', { signal: controller.signal });
controller.abort();

Ajax:

요청 취소 기능이 없음.

Axios:

const CancelToken = axios.CancelToken;
const source = CancelToken.source();

axios.get('/api/data', { cancelToken: source.token });
source.cancel('Request canceled');

g. 브라우저 호환성

  • Fetch: 최신 브라우저에서 지원. IE에서는 지원되지 않으므로 폴리필 필요.
  • Ajax: IE 포함 대부분의 브라우저에서 지원.
  • Axios: Fetch와 유사한 호환성. IE 지원 가능.

4. 언제 사용하면 좋을까?

Fetch

  • 간단한 HTTP 요청과 최신 브라우저만을 고려할 때.
  • 추가 라이브러리를 원하지 않을 때.

Ajax

  • 이미 jQuery를 사용하는 프로젝트에서 비동기 HTTP 요청이 필요한 경우.
  • IE와의 호환성을 반드시 고려해야 할 때.

Axios

  • 복잡한 HTTP 요청 로직이 필요할 때.
  • JSON 변환, 인터셉터, 요청 취소 등 부가 기능을 간단히 구현하고 싶을 때.
  • 브라우저와 Node.js 환경 모두에서 같은 코드를 사용할 때.

요약

  • Fetch: 가볍고 표준적이며 현대적. 추가 기능은 직접 구현해야 함.
  • Ajax: 전통적인 콜백 기반 요청 방식. jQuery 프로젝트에서 유용.
  • Axios: 기능이 풍부하고 사용이 간단하며, Fetch보다 직관적. 현대 웹 애플리케이션에 적합.
